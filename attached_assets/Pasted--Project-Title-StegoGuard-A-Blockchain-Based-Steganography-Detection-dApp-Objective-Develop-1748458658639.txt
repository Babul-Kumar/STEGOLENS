🛠 Project Title:
StegoGuard: A Blockchain-Based Steganography Detection dApp

🎯 Objective:
Develop a fully decentralized web application that allows users to:

Login securely using their crypto wallet (MetaMask)

Upload images for steganography detection (LSB + metadata + optional heatmap)

View a clear visual report

Store the report on IPFS

Write immutable logs to blockchain (smart contract)

Access historical reports via wallet lookup

🔐 Authentication: Wallet-based Sign In / Sign Up
✅ Use MetaMask wallet for Sign In / Sign Up (no passwords, no Firebase)

🚪 On first login, store:

Wallet address

Nickname (optional prompt)

Timestamp on blockchain

🔑 All login sessions managed using MetaMask + Web3 + JWT (optional for session)

📄 Features Breakdown
🔍 Steganography Detection (Python + Flask)
LSB extraction of pixel data

Attempt to decode the first 1000 bits to text

Show bit distribution, hidden patterns

Extract image metadata via exifread

Highlight suspicious regions (heatmap via OpenCV)

Show scan report summary

☁️ IPFS + Blockchain Integration
Upload final scan report (JSON, HTML) to IPFS

Interact with a Solidity Smart Contract that stores:

Wallet address

IPFS hash

Image SHA256 hash

Timestamp

Reports can be retrieved via wallet or image hash

🌐 Frontend UI (Pixel-Perfect)
Modern React UI with:

Home

Sign In / Sign Up with MetaMask

Upload & Scan Image

Report Display (highlight LSB results + metadata)

History page (shows past uploads from wallet)

Notifications, loading states, tooltips, success/error feedback

🧱 Tech Stack
🖥 Backend (Flask + Python)
Flask API for image analysis

pillow, numpy, opencv-python, exifread

ipfshttpclient: Upload JSON/HTML reports to IPFS

web3.py: Interact with smart contract

🌐 Frontend (React + Web3)
React + TailwindCSS for beautiful UI

MetaMask integration with ethers.js

Axios for Flask API interaction

QR-code compatible for wallet-based login

⛓ Blockchain Layer
Solidity smart contract deployed to Polygon Mumbai
